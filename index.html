◉PATH 01

AI & COMPUTER VISION

Teach software to notice what matters.

My surveillance project has helped me explore the path from camera frames to useful event signals. I’ve worked with Python and OpenCV and investigated object-detection workflows, motion-triggered recording and timestamped event logs.

The deeper lesson is that a model alone is not a full solution. Good systems also need sensible triggers, clear feedback, efficient storage and a plan for false detections. I want to keep learning about reliable on-device inference and edge constraints.

What this has taught meSeparate the detection problem from the recording and review workflow.
Python basicsOpenCVDetection workflows
⌁PATH 02

IOT & EMBEDDED SYSTEMS

Connect physical devices to useful controls.

Working with NodeMCU ESP8266 and M5Stack hardware has shown me how firmware, Wi-Fi connectivity, inputs and output actions fit together. I’ve explored device control and sensor-based experiments as practical ways to understand the link between code and the physical world.

Small hardware projects make reliability tangible: a connection can drop, a sensor can produce noisy readings, and an interface should make a device’s state easy to understand. My next step is to keep improving these prototypes and documenting their limits.

What this has taught meThink about the whole loop: input, decision, action, feedback and recovery.
ESP8266M5StackArduino IDEConnectivity
↗PATH 03

SALESFORCE & DATA

Make changing information easier to use.

The orbital telemetry dashboard brought together Salesforce Aura, Apex, REST API callouts, JavaScript polling and structured storage. The idea was to retrieve satellite information and present it in a form people could explore rather than leaving it scattered across API responses.

This work introduced me to the coordination required between a front end, server-side logic and external services. I also explored distance calculations and the role of well-structured records in future reporting and analysis.

What this has taught meA useful dashboard depends as much on clean data and dependable integration as on its visual design.
Salesforce AuraApexREST APIsJavaScript
↻PATH 04

WORKFLOW AUTOMATION

Give repetitive work a clearer path.

With Google Apps Script, I’ve explored ways to move information, process data and organise recurring tasks. My aim is to reduce avoidable manual steps while keeping the workflow understandable and easy to maintain.

Automation has encouraged me to think in sequences: what starts the process, what data it needs, what happens when a step fails, and how someone can verify the result. These questions matter whether a workflow is one short script or a larger business process.

What this has taught meAutomate a stable process, make its steps visible, and plan how to handle exceptions.
Google Apps ScriptData handlingProcess thinking
⌘PATH 05

SOFTWARE FOUNDATIONS

Keep strengthening the fundamentals.

My foundation includes Python and C++ at a basic level, object-oriented programming concepts, MySQL fundamentals, Git and GitHub, and hands-on use of the Arduino IDE. Coursework and Spoken Tutorial training have helped me practise core concepts in structured, assessment-based settings.

I’m continuing to improve how I break a problem into smaller steps, name and organise code clearly, trace errors and use version control to keep work organised. These are habits I want to carry into every new tool or platform.

What this has taught meStrong fundamentals make it easier to move between tools without losing sight of the problem.
